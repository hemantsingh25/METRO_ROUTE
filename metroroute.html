// DSA Concepts

Every concept,
exactly where it's used

The project is built to demonstrate these data structures and algorithms clearly — not just as buzzwords but as working code.

Graph
metro_graph.cpp
The metro network is modeled as a weighted undirected graph. Stations are vertices; connections between them are edges. The weight of each edge represents travel time in minutes.
Adjacency List
vector<vector<pair>>
Each station stores a list of its neighbors and the travel time. This is memory-efficient compared to an adjacency matrix — ideal for sparse metro networks.
Priority Queue
Dijkstra's core data structure
A min-heap priority queue always gives us the unvisited station with the smallest known distance, making Dijkstra's algorithm efficient at O(E log V).
Weighted Graph
Edge weights = travel time
Each edge between two stations carries a weight. Without weights, BFS would suffice — but with weights, we use Dijkstra to find the time-optimal route.
Map / unordered_map
Station name → ID lookup
Station names (strings) are mapped to integer IDs using unordered_map. This allows fast O(1) average-case lookup when the user types a station name.
Vector
Path storage & adjacency list
The reconstructed shortest path is stored in a vector of station IDs, then reversed to get source→destination order. The adjacency list is also a vector of vectors.
Path Reconstruction
parent[] array backtracking
After Dijkstra finishes, a parent array stores where we came from at each station. We trace back from destination to source, then reverse to print the route forward.
OOP — Classes & Objects
class MetroGraph
The MetroGraph class encapsulates all data (stations, graph) and behavior (addStation, findRoute) into one clean object, demonstrating basic OOP principles.
BFS vs Dijkstra
Design decision
BFS finds the route with fewest hops. Dijkstra finds the route with minimum total time. Since stations have different travel times, Dijkstra is the correct choice here.
// Algorithm

Dijkstra's
Algorithm

Dijkstra's algorithm finds the shortest path in a weighted graph. Starting from the source station, it repeatedly picks the nearest unvisited station, updates distances to neighbors, and continues until it reaches the destination.

It's the right choice here because metro edges have different travel times — a graph where BFS would give wrong answers but Dijkstra gives the optimal route.

time complexity
O(E log V)
space complexity
O(V + E)
metro_graph.cpp 
// Dijkstra's Algorithm for shortest metro route
void findShortestRoute(string src, string dest) {

  // Map station names to IDs
  int s = stationId[src];
  int d = stationId[dest];

  // dist[] stores shortest time to each station
  vector<int> dist(n, INT_MAX);
  vector<int> parent(n, -1);
  dist[s] = 0;

  // Min-heap: {distance, stationID}
  priority_queue<
    pair<int,int>,
    vector<pair<int,int>>,
    greater<>
  > pq;

  pq.push({0, s});

  while (!pq.empty()) {
    auto [d_u, u] = pq.top();
    pq.pop();

    if (d_u > dist[u]) continue; // stale entry

    for (auto [v, w] : adj[u]) {
      if (dist[u] + w < dist[v]) {
        dist[v] = dist[u] + w;
        parent[v] = u;       // track path
        pq.push({dist[v], v});
      }
    }
  }

  reconstructPath(parent, s, d, dist[d]);
}

// Viva Preparation

30 likely questions,
simple answers

Every answer is kept short enough to memorize and explain clearly. Focus on the why, not just the what.

What is a graph?
A data structure made of vertices (nodes) and edges (connections). Here, stations are vertices and tracks are edges.
Why did you use a graph?
Metro stations connect to each other in a network — not a line or tree. A graph naturally models this many-to-many relationship.
What is an adjacency list?
A list where each station stores its neighbors and edge weights. More memory-efficient than an adjacency matrix for sparse graphs.
Why Dijkstra and not BFS?
BFS finds the path with fewest hops. Dijkstra finds the path with minimum total weight (travel time). Our graph has weighted edges, so Dijkstra is correct.
What is a priority queue?
A heap that always returns the element with the minimum (or maximum) priority. In Dijkstra, we use a min-heap to pick the nearest unvisited station.
Time complexity of Dijkstra?
O(E log V) with a binary heap priority queue. E = edges, V = vertices (stations).
What is path reconstruction?
After Dijkstra runs, we use a parent[] array to trace back from destination to source, then reverse the list to get the correct order.
What is a class in C++?
A blueprint for creating objects. Our MetroGraph class holds the station data and all functions needed to operate on the metro network.
What is a vector?
A dynamic array in C++ STL that can grow in size. We use vectors to store the adjacency list and the reconstructed path.
What is an unordered_map?
A hash map that gives O(1) average-case lookup. We use it to convert station names (strings) to integer IDs in constant time.
What happens if station name is invalid?
We check if the name exists in the unordered_map before processing. If not, we print an error message and ask the user to try again — no crash.
What if source equals destination?
We handle this as a special case: print "You are already at the destination" and return without running Dijkstra.
Why are edge weights important?
Without weights, all connections are equal. Weights let us represent that some routes take longer, so the algorithm can find the time-optimal path.
What is OOP and where did you use it?
Object-Oriented Programming organizes code into classes and objects. We created a MetroGraph class with data (stations, graph) and methods (addStation, findRoute).
Can Dijkstra handle cycles in the graph?
Yes. It tracks visited stations and only processes a station when the shortest distance to it is confirmed — cycles don't cause infinite loops.
What is the space complexity?
O(V + E) for storing the graph, plus O(V) for the dist[] and parent[] arrays. Total: O(V + E).
Does Dijkstra work with negative weights?
No. Dijkstra assumes all edge weights are non-negative. Travel times are always positive, so this is not an issue in our project.
What is encapsulation?
Bundling data and the functions that operate on it into a single class. The MetroGraph class encapsulates graph data and all routing logic.
How do you compile with MinGW/G++?
Run: g++ -o metroroute main.cpp and then ./metroroute. The project uses only standard C++ libraries, so no extra flags needed.
What are the limitations of this project?
It's console-only (no GUI), uses a simulated network (not real GPS data), and doesn't account for fare, real-time delays, or interchange time.
How can this be improved?
Add a GUI, integrate real metro maps via APIs, include fare calculation, add real-time delay simulation, support for multiple route options.
What is a weighted undirected graph?
A graph where edges have weights (travel time) and can be traversed both ways — if A connects to B in 5 min, B connects to A in 5 min too.
What does the parent[] array store?
For each station, parent[v] = u means "we reached v from u on the shortest path." This lets us trace the route backward from destination.
What is INT_MAX and why use it?
It represents infinity — the largest possible integer value. We initialize all distances to INT_MAX to mean "not reached yet," then update them as we explore.
What is the difference between a stack and a queue?
Stack is LIFO (last in, first out). Queue is FIFO (first in, first out). A priority queue is a specialized queue that always removes the element with highest priority first.
Where is string handling used?
Station names are stored as strings. We use getline() to read names with spaces, and unordered_map to convert them to IDs.
What real-world application does this have?
Google Maps, Uber routing, airline route planners, and actual metro apps (Delhi Metro, London Tube) all use variants of shortest-path algorithms on graphs.
What is modularity in programming?
Breaking the code into separate functions with one job each. We have addStation(), findShortestRoute(), displayRoute() — each does one thing and can be tested independently.
Why use a pair in the priority queue?
The pair stores {distance, stationID} together so we can sort by distance while keeping track of which station we're referring to.
What is the difference between BFS and Dijkstra in terms of data structures?
BFS uses a regular queue (FIFO). Dijkstra uses a priority queue (min-heap) so it always processes the nearest unvisited node next — that's what makes it optimal for weighted graphs.
